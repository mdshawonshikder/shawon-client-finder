SHAWON AI CLIENT FINDER PRO v6.0 — INTERNATIONAL
=================================================
Primary services:
1. Logo & Branding
2. Website Design
3. App Development

Target markets:
USA, UK, Canada, Australia, Germany, France, Netherlands, Switzerland,
Sweden, Norway, Denmark, Ireland, New Zealand and Singapore.
Default target: New York, United States.

WINDOWS SETUP
1. Install Python 3.10+ from python.org and tick "Add Python to PATH".
2. Extract this ZIP to a normal folder (for example Desktop\SHAWON_CLIENT_FINDER).
3. Double-click RUN_SHAWON_PRO.bat.
4. The launcher installs customtkinter if missing and opens the app.
5. Internet is needed for online business search, website checks and online AI services.

NO FIREBASE REQUIRED
- Leads are stored in a local SQLite database file in the app folder.
- No Firebase project, server, domain, or cloud database is required.
- Keep the database file and make regular backups.
- To share leads between computers, you would need a separate sync/cloud setup; V6 does not include that.

V6 FEATURES
- Choose the service: Logo & Branding, Website Design, or App Development.
- Google/Bing open focused searches for public project requests and hiring signals.
- CRM saves the selected service instead of guessing from whether a business has a website.
- Lead scoring gives more weight to explicit buying-intent phrases; basic website issues are weak signals.
- International business directory search, website checks and public contact discovery remain available.

LIMITATIONS
- Google/Bing searches open in your browser. Results are not scraped or auto-imported.
  Review the original source, date, business and contact details, then add valid prospects to CRM.
- OpenStreetMap coverage is incomplete and varies by location/category.
- A business directory listing is a prospect, not proof it wants to buy.
- A missing or weak website is not proof that the business wants a redesign.
- Website checks are heuristic, not a full SEO/security audit.
- Email syntax/MX/DNS checks do not confirm a specific mailbox exists or accepts messages.
- AI provider quotas/availability can change. Optional API keys are not required for local CRM.
- Use public business contacts, personalize outreach, honor opt-outs and comply with target-country
  privacy and anti-spam laws.
